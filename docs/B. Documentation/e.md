# Static web sites

Over the years, I just got very fed up moving my teaching notes from one platform to another, each time something changed in the teaching environment. In the 2020s, I decided to move off all proprietary platforms and put my notes back into HTML.

So the easy way to do that...

I decided to use [GITHUB Pages](https://docs.github.com/en/pages) to host my material for now, but if it is in HTML, I can move it anywhere.

Writing code in HTML is messy, so I used a static site generator to convert from markdown to HTML. I decided on [MKDocs](https://www.mkdocs.org/) as being the right balance between simplicity and quality. My design skills are questionable, I draw very pretty straight lines, but art....

DEo a little reading on these tools, but you do not need to do any exercises.
